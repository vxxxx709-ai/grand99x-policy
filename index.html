เงื่อนไขการใช้งาน (Terms of Service)

  • ผู้ใช้ต้องใช้บัญชี Discord ของตนเองในการเข้าใช้บริการ
  • การสมัครสมาชิกอาจต้องกรอกชื่อเล่น อายุ เหตุผลในการสมัคร และประสบการณ์ตามที่ระบบร้องขอ
  • ห้ามใช้บริการเพื่อก่อกวน หลอกลวง ส่งสแปม หรือสร้างความเสียหายแก่ผู้อื่น
  • ทีมงานสามารถตรวจสอบคำขอและพิจารณาอนุมัติหรือปฏิเสธการสมัครได้
  • ทีมงานอาจระงับการใช้งานเมื่อพบการละเมิดเงื่อนไข
  • ระบบร้านค้าในขณะนี้เป็นเพียงระบบตัวอย่าง ไม่มีการชำระเงินจริงหรือเติมเครดิตเงินจริง
  • บริการอาจมีการเปลี่ยนแปลงเพื่อปรับปรุงระบบ โดยจะแจ้งเมื่อมีความจำเป็น

บริการนี้เชื่อมต่อกับ Discord ซึ่งเป็นบริการภายนอกและอยู่ภายใต้เงื่อนไขของ Discord ด้วย

หากมีข้อสงสัย สามารถติดต่อทีมงานผ่านช่องทาง Ticket ภายในเซิร์ฟเวอร์

นโยบายความเป็นส่วนตัว (Privacy Policy)

GRAND 99X เก็บและใช้ข้อมูลเท่าที่จำเป็นต่อการให้บริการ ได้แก่

  • Discord User ID และชื่อบัญชี Discord
  • ข้อมูลที่ผู้ใช้กรอกในแบบฟอร์มสมัคร เช่น ชื่อเล่น อายุ เหตุผล และประสบการณ์
  • ข้อมูลที่จำเป็นต่อการตรวจสอบคำขอและมอบยศสมาชิก

การใช้ข้อมูล

  • ใช้ตรวจสอบตัวตนผ่าน Discord OAuth
  • ใช้ดำเนินการสมัครสมาชิกและมอบยศ MEMBER
  • ใช้แสดงข้อมูลคำขอในห้อง Ticket แก่ผู้สมัครและทีมงานที่ได้รับอนุญาต

การเข้าถึงและการลบข้อมูล

ข้อมูลคำขออาจปรากฏในห้อง Ticket จนกว่าห้องดังกล่าวจะถูกปิดและลบตามการทำงานของระบบ การลบห้องไม่ได้รับประกันว่าข้อมูลสำรองของ Discord จะถูกลบทันที

ระบบใช้ OAuth Access Token เพื่อดำเนินการที่จำเป็นกับ Discord โดยไม่ควรนำไปเปิดเผยแก่บุคคลอื่น

บริการภายนอก

การเข้าสู่ระบบใช้บริการ Discord ข้อมูลที่ส่งไปยัง Discord อยู่ภายใต้นโยบายความเป็นส่วนตัวของ Discord
